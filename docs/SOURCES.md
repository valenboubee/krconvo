# Sources

Every conversation records where its text came from, per the copyright/content
rule in the build spec (§2). Allowed `source:` values in a module's frontmatter:

- `supplied` — dialogue text the learner supplied to the app (e.g. from a book they own).
- `learner-authored` — written by the learner.
- `original` — original course content written for this app.
- `adapted` — adapted from a supplied source (paraphrased, not copied).

**Rule:** Do not reproduce large amounts of copyrighted source material into
content files unless the learner supplied that text. New course dialogues are
written original, not copied from published books.
